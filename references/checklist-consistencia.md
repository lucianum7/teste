# Checklist de Consistência

## Partes
- [ ] nome correto;
- [ ] gênero correto;
- [ ] empresa correta;
- [ ] cidade correta;
- [ ] função correta;
- [ ] datas corretas;
- [ ] remuneração correta;
- [ ] jornada correta.

## Estrutura
- [ ] numeração sequencial;
- [ ] sem tópicos duplicados;
- [ ] sem saltos acidentais;
- [ ] família decimal preservada.

## Corpo x pedidos
- [ ] todo pedido tem fundamentação;
- [ ] toda pretensão fundamentada aparece no quadro;
- [ ] rubrica usa o mesmo nome;
- [ ] percentuais coincidem;
- [ ] períodos coincidem;
- [ ] reflexos coincidem;
- [ ] valores coincidem.

## Dano moral
- [ ] fato gerador individualizado;
- [ ] prejuízo do caso concreto;
- [ ] fecho obrigatório;
- [ ] valor adaptado;
- [ ] enquadramento validado.

## Resíduos
- [ ] nenhum nome de outro cliente;
- [ ] nenhuma empresa de outro processo;
- [ ] nenhum horário antigo;
- [ ] nenhuma rubrica estranha;
- [ ] nenhuma doença/acidente alheio;
- [ ] nenhuma duplicidade textual.
